## 📌 Tentang Mod / About The Mod

**Sleeping Dogs: Definitive Edition - Practice Mod by Ceplin** adalah mod komprehensif berbasis ASI plugin C++ yang dirancang untuk memperluas pengalaman seni bela diri dan pertarungan tangan kosong (*hand-to-hand combat*) di Sleeping Dogs Definitive Edition.

Mod ini menghadirkan fitur tantangan **Dojo Survival Gauntlet bertingkat** (hingga 20 musuh bersenjata dan Duo Boss), **Duel 1v1 Boss & Master Ikonik**, **Fighting Game HUD Overlay bergaya arcade**, **Pengganti Gaya Bertarung (Moveset Switcher)**, **Teleportasi ke 14 Arena Ikonik**, serta **Sistem Dwibahasa (Bahasa Indonesia & English)** yang dapat diganti secara langsung di dalam game.

---

## 🎮 File Mod yang Digunakan / Mod Binary Files

Jika Anda mengunduh dari rilis rilis GitHub (*Releases*), file yang Anda perlukan adalah:

| Nama File | Fungsi | Lokasi Instalasi |
|---|---|---|
| **`PracticeMode.asi`** | Binary utama Practice Mod buatan **Ceplin** | Letakkan di folder utama game (tempat `sdhdship.exe`) |
| **`dinput8.dll`** | Ultimate ASI Loader x64 (pemuat file `.asi`) | Letakkan di folder utama game (tempat `sdhdship.exe`) |

> 📁 File yang sudah di-build berada di direktori lokal: **`bin/PracticeMode.asi`** dan **`bin/dinput8.dll`**.

## 🌟 Fitur Unggulan / Key Features

### 1. 🌐 Sistem Dwibahasa Dinamis / Dynamic Dual-Language System
- Tombol radio switch instan di header menu: **`[Bahasa Indonesia]`** & **`[English]`**.
- Seluruh teks antarmuka, deskripsi jurus, tips mode kesulitan, banner pertarungan, hingga modal evaluasi laporan dapat dinikmati dalam 2 bahasa tanpa me-reset tab yang sedang dibuka.

### 2. 🥋 Dojo Survival Gauntlet (Tantangan Bertingkat & Mode Endless)
- **3 Tingkat Kesulitan:**
  - **Easy (5 Ronde):** 2–5 musuh, senjata ringan, pemulihan HP +50% tiap ronde.
  - **Medium (7 Ronde):** 3–7 musuh, variasi senjata, Mini-Boss Duke & Dragonhead Big Smile Lee.
  - **Hard Brutal (10 Ronde):** Skala pertempuran massal dari 5 hingga **20 musuh bersenjata sekaligus**, pertarungan **Duo Boss** serempak (Karl & George, Mr. Tong & Big Fu, Big Smile Lee & Duke), serta fitur **Lifesteal HP** saat menjaga combo 10+ hits!
- **Kustomisasi Senjata Musuh (NPC Weapons):** Dinamis, Tangan Kosong murni, Senjata Tumpul, Senjata Tajam (Golok/Parang/Pisau), atau Acak Campuran.
- **Override Jumlah Musuh:** Slider fleksibel untuk memaksa jumlah musuh (1 s.d. 20 musuh per gelombang).
- **Laporan Ringkasan Modal:** Statistik lengkap setelah ronde selesai (Skor, Waktu, Kills, Total Damage, Combo Tertinggi, dan Peringkat dari `SSS+ Immortal Dragon` hingga `C Novice`).

### 3. ⚔️ Tantangan Duel Boss & Master 1v1 (Iconic Boss Sparring)
- Sparring 1v1 melawan 12 karakter legendaris:
  - **Big Smile Lee** (Dragonhead Final Boss)
  - **Duke** (Underground Heavyweight Unblockable)
  - **Dog Eyes** (Pemimpin Geng Jade - Swift Knife)
  - **Mr. Tong** (Master Pedang Golok Sun On Yee)
  - **Ponytail** (Letnan Akrobatik)
  - **Sifu Henry Kwok** (Guru Besar Bela Diri Wei Shen)
  - **Karl** (Juara Muay Thai Zodiac Island)
  - **George** (Juara MMA/UFC Zodiac Island)
  - **Master Song** (Shaolin Grandmaster)
  - **Master Quan** (Zodiac Champion)
  - **Big Fu** (Fu Brothers Brute)
  - **Conroy** (Triad Brawling Enforcer)
- Pengganda HP Boss (**1x, 2x, 3x, 5x Raid Boss**) dan opsi **Boss Invulnerable** untuk melatih variasi combo tanpa batas.

### 4. 🥊 Gelombang & AI Combat Class (AI Sparring Spawner)
- Pengaturan kelas bertarung AI musuh:
  - **Dummy Sandbag Pasif** (musuh diam tidak melawan untuk latihan timing pukulan & juggle).
  - **Striker** (pukulan beruntun cepat).
  - **Quick Striker** (lincah, sering sidestep & counter).
  - **Brawler Striker** (pukulan keras berbobot tinggi).
  - **Grappler** (spesialis bantingan & kuncian lantai).
  - **Enforcer** (tahan stagger pukulan, serangan unblockable).
  - **Elite Master** (tangkisan parry & reversal).
- 12 Preset jenis model musuh (Preman jalanan, geng 18K, murid perguruan kungfu, polisi, dsb.).

### 5. 🥋 Gaya Bertarung Wei Shen (Moveset Switcher)
Ubah gaya bertarung dan animasi serangan Wei Shen secara langsung:
- **Drunken Master (Drunken Fist):** Langkah goyang tak terduga, elakan mendadak, & counter unik.
- **Wing Chun (Lightning Warrior):** Pukulan beruntun super cepat di garis tengah (*chain punch*) & parry kilat.
- **Muay Thai Champion:** Kombinasi sikutan tajam mematikan, clinch lutut, dan flying knee.
- **MMA / UFC:** Takedown bantingan dua kaki, pertarungan lantai agresif, & hook bertenaga.
- **Bruce Lee / Jeet Kune Do:** Jumpsuit legendaris, tendangan kilat JKD, kelincahan tinggi.
- **Shaolin Monk Master:** Pukulan telapak tangan bertenaga & sapuan kaki bawah.
- **Retro 80s Triad Enforcer:** Brawling jalanan kasar Hong Kong, adu fisik keras & sundulan kepala brutal.
- Opsi untuk kembali ke pakaian dan animasi standar Wei Shen kapan saja.

### 6. 📍 Teleportasi 14 Arena Latihan Ikonik & Custom Coordinates
- Dojo Interior & Courtyard Sifu Kwok
- Zodiac Island Temple Arena
- Aberdeen Fish Market (Fight Club)
- Central & North Point Gambling Den (Fight Pit)
- Club Bam Bam (Dancefloor)
- Two Chin's Mansion (Pavilion & Courtyard Pit)
- Warehouse / Pabrik Impor-Ekspor
- Mrs. Chu's Restaurant (Alleyway)
- Helipad Rooftop RS Central
- Penthouse Kennedy Town & Safehouse North Point
- **Fitur Custom Position:** Simpan posisi koordinat Wei Shen saat ini dan lakukan teleportasi kembali kapan pun.

### 7. 📊 Arcade Fighting Game HUD & Analytics Telemetry
- **Floating 3D Damage Numbers:** Angka damage dinamis yang melayang di atas musuh (Hit biasa, Critical Hit, K.O.!).
- **Arcade Target Health Bar:** Bar HP musuh di atas layar dengan gradasi warna dinamis serta indikator *damage lag* merah.
- **Arcade Combo Counter:** Indikator combo hits, decay timer bar, total combo damage, dan gelar rating kombo (*GOOD*, *GREAT*, *EXCELLENT*, *BRUTAL*, *MASTER*, *LEGENDARY SIFU*).
- **Combat Telemetry:** Menghitung real-time DPS (Damage Per Second), total damage dealt/taken, total kills, dan combo tertinggi.

### 8. 🛠️ Pelatihan & Rak Senjata (Training Helpers)
- Cheat toggle: God Mode, Infinite Face Meter, Infinite Ammo, Full Health Restore.
- Spawner senjata langsung ke tangan Wei Shen: Golok (Meat Cleaver), Tongkat Polisi (Baton), Kunci Roda (Tire Iron), Pisau Dapur, Linggis (Crowbar), Parang (Machete), Pistol 9mm, dan Pump Shotgun.
- Tombol lepas senjata instan (kembali ke tangan kosong).

## 📥 Panduan Instalasi / Installation Guide

1. Pastikan Anda memiliki **Sleeping Dogs: Definitive Edition** (Steam / GOG).
2. Salin file **`PracticeMode.asi`** dan **`dinput8.dll`** ke folder utama instalasi game Anda:
   ```
   [Folder Instalasi Game]/
   ├── sdhdship.exe
   ├── dinput8.dll          <-- Letakkan di sini
   ├── PracticeMode.asi     <-- Letakkan di sini
   └── ...
   ```
3. Jalankan game Sleeping Dogs: Definitive Edition seperti biasa.
4. Masuk ke gameplay (bebas jalanan atau misi), lalu tekan **`F5`** pada keyboard untuk membuka menu mod.

## 🔨 Panduan Kompilasi dari Source Code / Build Instructions

Jika Anda ingin memodifikasi atau meng-compile sendiri mod ini:

### Persyaratan:
- **Visual Studio 2019 / 2022** atau **Visual C++ Build Tools** (dengan komponen C++ x64).
- Windows 10 / 11 64-bit.

### Langkah Build:
1. Clone repositori ini:
   ```bash
   git clone https://github.com/USERNAME/SD-Practice-Mod-Ceplin.git
   cd SD-Practice-Mod-Ceplin
   ```
2. Cukup jalankan skrip build otomatis:
   ```cmd
   build.bat
   ```
3. Skrip akan otomatis mengkompilasi file C++ dan MinHook menggunakan standar `/std:c++20 /O2`, menghasilkan output di **`bin/PracticeMode.asi`**, dan secara otomatis menduplikasi file tersebut ke folder game jika ditemukan.
